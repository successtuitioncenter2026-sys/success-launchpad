# Success Tuition Center Website

Official website for Success Tuition Center, Katpadi, Vellore.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
```

## Deployment

This project is ready for Netlify deployment.

- Build command: `npm run build`
- Publish directory: `dist`

Netlify SPA redirect support is already included through:

- `netlify.toml`
- `public/_redirects`
